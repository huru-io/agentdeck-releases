# AgentDeck downloads

The AgentDeck apps, ready to install. (The source is private; these are the builds.)

- **Mac (Apple silicon):** [AgentDeck.dmg](https://github.com/huru-io/agentdeck-releases/releases/latest/download/AgentDeck.dmg)
  — open it, drag AgentDeck into Applications. First launch: macOS 15+ System Settings → Privacy & Security →
  **Open Anyway** (macOS 14: right-click the app → Open). It isn't signed yet.
- **Linux, Android, CLI and TUI:** coming to the same [Releases](https://github.com/huru-io/agentdeck-releases/releases) page.

Then: **Connect to…** your AgentDeck server's https address (or use the desktop app's own server on this computer).
